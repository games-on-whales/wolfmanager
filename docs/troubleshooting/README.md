## Getting Help

If you're experiencing an issue not covered in these guides:

1. Check the [diagnostic tools](../debug/) built into WolfManager
2. Review the [GitHub Issues](https://github.com/games-on-whales/wolfmanager/issues)
3. Create a new issue with detailed information about your setup and the problem

## Diagnostic Tools

WolfManager includes several built-in diagnostic tools:

- **Wolf Connection Test**: `/debug/wolf-connection` - Tests Wolf socket connectivity
- **API Test Console**: `/settings/api-test` - Interactive API endpoint testing
- **Logger Configuration**: `/api/debug/logger-config` - View current logging configuration
