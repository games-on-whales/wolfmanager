# Validation Scripts

This directory contains validation and testing scripts for various WolfUI components.

## Files

### Environment Variable Auto-Generation Tests

- **`test-auto-generation.js`** - Comprehensive test suite for NEXTAUTH_SECRET auto-generation
  - Tests fresh installation scenarios
  - Tests existing environment variable preservation
  - Tests partial environment variables
  - Tests error handling and Docker configuration
  - Generates `test-results.json` with detailed results

- **`test-env-generation.js`** - Direct test of the `ensureSecureKeys` function
  - Tests TypeScript compilation and execution
  - Validates environment variable formats
  - Tests randomness and uniqueness

- **`validate-auto-generation.js`** - Manual validation script for NEXTAUTH_SECRET implementation
  - Validates current auto-generated secrets
  - Tests secret preservation across restarts
  - Validates Docker configuration
  - Checks instrumentation integration
  - Validates logging security

### Configuration Validation

- **`validate-toml.js`** - Simple TOML file validation script
  - Validates `config/tasks.toml` syntax
  - Outputs parsed structure for debugging

### Test Results

- **`test-results.json`** - Output from automated test runs
  - Contains test execution results and timestamps
  - Generated by `test-auto-generation.js`

## Usage

These validation scripts are maintained as part of the codebase for:

1. **Documentation** - Understanding how the auto-generation functionality is tested
2. **Debugging** - Troubleshooting environment variable issues in development
3. **Validation** - Verifying security requirements are met
4. **CI/CD Integration** - Potential automated testing in build pipelines
5. **Future development** - Reference for additional validation needs

### Running the Scripts

```bash
# Comprehensive auto-generation testing
node tests/validation/test-auto-generation.js

# Direct function testing
node tests/validation/test-env-generation.js

# Manual validation
node tests/validation/validate-auto-generation.js

# TOML configuration validation
node tests/validation/validate-toml.js
```

## Note

- Test scripts are tracked in version control for team collaboration
- Test results (`test-results.json`) and logs are excluded from Git and Docker builds
- Scripts are designed to be safe and restore original state after testing
